# 群馬県リース市場における主要参入リース会社の特定とシェア調査 報告書

本セクションでは、群馬県内の一般リース市場（年間取扱規模：約610億〜680億円）および広義のリース・レンタル市場（約950億〜1,100億円）を対象に、**主要参入リース会社の特定、拠点展開、事業特性、および市場シェアの推計・分析**を行います。

---

## 1. 群馬県リース市場の競争環境（全体俯瞰）

群馬県のリース市場は、圧倒的なシェアを誇る**「地銀系リース会社」**、大手製造業の基盤を握る**「メガバンク・総合リース会社（5社）」**、そして特定の強みを持つ**「独立系・メーカー系リース会社」**が三つ巴の激しいシェア争いを展開しています。

### 競争構造の3大極

```
　　　　　　　【群馬県リース市場の競争構造】
 
         ┌──────────────────────────────────────┐
         │     地銀系（圧倒的な地域密着・リテール）      │
         │   ●群銀リース (群馬銀行の強固な顧客基盤)   │
         │   ●東和リース (東和銀行系、中小密着)        │
         └──────────┬───────────────────────┬──────────┘
                    │                       │
                    │ 競合・協調             │ 競合
                    │                       │
 ┌──────────────────┴──┐             ┌──────┴───────────┐
 │ 大手総合（大型・製造業・DX） │             │ メーカー・独立・特定分野      │
 │  ●三菱HC / SMFL / みずほ    │  競合・住み │  ●オリックス (総合・オート)   │
 │  ●東京センチュリー / 芙蓉総合│  分け       │  ●リコーリース (OA・医療)    │
 │   (高崎支店を拠点に営業展開) │             │  ●JA三井リース (農業・食品)   │
 └──────────────────────┘             └───────────────────────┘
```

1.  **地銀系（地元圧倒シェア）**：
    *   **群銀リース**が群馬銀行のメインバンクシェア（県内約50%）を背景に、中小・中堅企業市場をほぼ面で押さえています。
2.  **大手総合リース（大手・中堅製造業向け、再エネ、自治体）**：
    *   高崎駅周辺に拠点を構えるメガバンク・商社系リース会社。SUBARU（スバル）およびそのサプライチェーン（1次・2次部品メーカー）の大型機械・プラント投資、自治体向けリースなどを獲得。
3.  **メーカー系・独立系・特定分野（リテール・OA・農業等）**：
    *   オフィス機器に強いリコーリース、多角的な提案を行うオリックス、農業県としての群馬を支えるJA三井リースなどが各領域で強みを発揮しています。

## 2. 主要参入リース会社のプロファイル

群馬県内に拠点を置く、または県内市場で強い影響力を持つ主要リース会社の詳細情報です。

### (1) 地銀系リース会社

#### ① 群銀リース株式会社（県内絶対王者）
*   **本社所在地**：群馬県前橋市元総社町142番地の1
*   **株主構成**：株式会社群馬銀行 100%（連結子会社）
*   **営業収益（売上高）**：**約 263億円**（2023年3月期実績）
*   **群馬県内拠点**：本社（前橋市）。ただし、群馬銀行の県内約80店舗の支店網と完全連動した営業体制を敷く。
*   **サービス展開状況**：一般リース（工作機械、情報機器、商業設備等）、割賦販売、金銭貸付、オートリース（群銀オートリースと連携）。近年は「SDGsリース」「ポジティブ・インパクト・リース」など、ESG/カーボンニュートラル支援に注力。

#### ② 東和リース株式会社
*   **本社所在地**：群馬県前橋市本町一丁目10番2号
*   **株主構成**：東和銀行グループ
*   **営業収益（売上高）**：約 30億円（推計）
*   **群馬県内拠点**：本社（前橋市）および東和銀行の店舗網。
*   **サービス展開状況**：東和銀行の取引先である中小企業・小規模事業者をターゲットとした地域密着型の各種設備リース・割賦。

---

### (2) 大手総合リース会社（高崎支店を設置するプレイヤー）

高崎市は北関東（群馬・栃木・新潟）の交通・経済の結節点であるため、大手総合リース各社は**「高崎支店」**を設置し、群馬県を中心とした広域営業を行っています。

#### ③ 三菱HCキャピタル株式会社（高崎支店）
*   **高崎支店所在地**：群馬県高崎市八島町265番地（高崎中央ビル）
*   **事業特徴**：旧三菱UFJリースと日立キャピタルの統合により、製造業の「産業機械・工作機械」に極めて強い。日立グループ系ベンダーリース網も引き継いでおり、工場自動化（FA）投資やITインフラで高い実績。

#### ④ 三井住友ファイナンス＆リース株式会社（SMFL、高崎支店）
*   **高崎支店所在地**：群馬県高崎市栄町14番1号（高崎イーストタワー）
*   **事業特徴**：三井住友フィナンシャルグループ。スバル系列などの超大手企業向け大型設備投資、環境・エネルギー（メガソーラー等の脱炭素設備）における実績が豊富。

#### ⑤ みずほリース株式会社（高崎支店）
*   **高崎支店所在地**：群馬県高崎市宮元町212番地（高崎フロントビル）
*   **事業特徴**：みずほフィナンシャルグループおよび丸紅との協業。大手ベンダー（販売会社）と提携した設備リース、商社ルートを活用した産業機械、IT機器リースに強み。

#### ⑥ 東京センチュリー株式会社（高崎支店）
*   **高崎支店所在地**：群馬県高崎市栄町3番11号（高崎マークビル）
*   **事業特徴**：伊藤忠商事グループおよび旧第一勧業銀行系。ITリース（ライフサイクルマネジメント）やオートリース（日本カーソリューションズ等と連携）に極めて強く、太陽光発電等の環境アセットでも群馬県内に多数の稼働実績。

#### ⑦ 芙蓉総合リース株式会社（高崎支店）
*   **高崎支店所在地**：群馬県高崎市東町9番地（東町ビル）
*   **事業特徴**：みずほグループ。医療機器リース（MRI・CT等、県内の病院・クリニック向け）、地方自治体向けの庁舎設備・情報インフラのリース、BPO（業務受託）サービスの提案等、ニッチ・専門領域に強み。

---

### (3) メーカー系・独立系・その他の主要プレイヤー

#### ⑧ オリックス株式会社（高崎支店）
*   **高崎支店所在地**：群馬県高崎市栄町3番11号（高崎マークビル）
*   **事業特徴**：独立系の強みを活かし、一般リース・オートリースからIT機器・計測器レンタル（オリックス・レンテック）、環境エネルギー事業まで幅広く対応。中小企業の経営コンサルティング的なアプローチで直接取引が多い。

#### ⑨ JA三井リース株式会社（群馬支店）
*   **群馬支店所在地**：群馬県前橋市南町三丁目9番地5（JA群馬ビル）
*   **事業特徴**：農協（JA）グループのバックボーンを活かし、群馬県内の「農業設備」（トラクター、選別機、ビニールハウス等）、「食品加工設備」、「流通・倉庫設備」において独占的なシェアを有する。

#### ⑩ リコーリース株式会社（北関東エリア担当）
*   **営業体制**：大宮支店（さいたま市）等から群馬県をカバー、またはサテライト展開。
*   **事業特徴**：複合機（コピー機）、PC、POSレジ等のオフィスIT機器、および歯科医院・クリニック向け医療機器、レセコンのリースで抜群のシェア。中小企業向けリテールリースの雄。

## 3. 群馬県リース市場（一般リース）のシェア分析・推計

群馬県における一般リース市場規模（年間契約取扱高：約650億円）に占める各社の獲得シェアを、各社公開情報（業績、拠点展開、親会社シェア）および産業特性（製造業比率、メインバンクシェア）から論理的に推計しました。

### 【推計】群馬県一般リース年間取扱高シェア（2023〜2024年ベース）

### シェア分析のキーポイント
1.  **群銀リースの「圧倒的一強」構造**：
    *   シェア36.9%と、2位以下に大差をつけてトップ。群馬銀行という絶対的な「地元の信用インフラ」に紐づいているため、県内中小企業の多くは「初めてのリース」や「主要な設備投資」に群銀リースを選択します。
2.  **大手総合5社の激戦区（合計シェア約30%）**：
    *   大手5社のシェア（三菱HC、東京C、SMFL、みずほ、芙蓉）を合計すると**約30.4%（約197億円）**となり、群銀リースに匹敵する勢力となります。
    *   彼らの主戦場は「高崎・太田・伊勢崎」の工業集積地帯。1件あたり数億円から数十億円にのぼる大規模な「工場のライン新設」や「環境発電システム」を巡り、低金利や財務ソリューションを武器に競い合っています。
3.  **専門特化によるニッチ・トップの確立**：
    *   **JA三井リース**は、一般リース全体ではシェア4.9%（32億円）ですが、**「農業・食品加工・流通」セクターに限れば、群銀リースをしのぐシェア**を持つと推測されます。
    *   **リコーリース**は、OA複合機や小規模医療機関（クリニック）向けリテールで安定した「高収益・高シェア」を誇り、地銀系と価格競争をしないポジションを確立しています。

## 5. 特化セグメント（オートリース・建機等）の競合状況

前ステップ（市場規模推計）で明らかになった、広義のリース・レンタル枠（約300億〜400億円）における主要プレイヤーの状況です。

### (1) オートリース（自動車リース）市場：約 180億〜220億円
群馬県は「1世帯当たりの自家用車保有台数」が全国屈指の超車社会であり、企業の営業車、トラック、福祉車両などのリース需要が極めて旺盛です。

*   **日本カーソリューションズ（NCS）**および**住友三井オートサービス（SMA）**：
    *   大手総合リースの系列（東京センチュリー、SMFL等）として、県内の大口法人フリート（数十台〜数百台所有）をほぼ占有。
*   **オリックス自動車**：
    *   法人営業車だけでなく、レンタカー・カーシェアリングとも連携し、中堅・中小向けで強い。
*   **群銀リース（群銀オートリース連携） / 地元ディーラー系（群馬トヨペット等）**：
    *   「数台規模」の地元中小企業、個人事業主向け。きめ細かな点検・車検サービス（コミコミプラン）を武器に、リテール領域を完全に支配。

### (2) 建設機械レンタル・リース市場：約 160億〜200億円
山間部が多く、災害対策、高速道路網（関越・北関東等）の維持補修が多い群馬県では、建機レンタルが活発です。

*   **アクティオ（AKTIO）**：県内に「高崎営業所」「前橋営業所」など多数のテクノパーク・デポを設置し、最大シェア。
*   **カナモト**：前橋、太田等に拠点を展開。土木・道路用建機に強み。
*   **西尾レントオール**：イベント用、高所作業車等で強みを発揮。

## 6. まとめと次のステップ（リース会社シェアから見える営業戦略）への接続

本ステップの調査から、群馬県のリース市場における以下の構造的ダイナミクスが判明しました。

1.  **「群銀リース」という堅牢な要塞**：
    *   県内約37%のシェアを握る群銀リースの牙城は極めて強固です。地元の信用力、銀行からの紹介ルート、スピード面で他社の追随を許しません。
2.  **大手総合リースの「高崎戦略」**：
    *   大手リース各社は、高崎支店を前線基地に据え、**「群銀リースが対応しにくい大型製造アセット」「DX（LCM）推進」「脱炭素（再エネ・EV）」**の3軸を切り口に、群馬県の成長セクターに深く食い込んでいます。
3.  **異業種・特定分野のポテンシャル**：
    *   群馬県の特性である「製造業（ものづくり県）」に加え、日本屈指の「農業県」という側面から、JA三井リースの存在感や、車社会を背景としたオートリース会社の営業密度が高いのも特徴です。

### 次のステップへの接続（リース会社のシェアを踏まえた競合優位性の構築）
次のステップでは、これらの競合他社のポジショニングを踏まえ、どのようにして群馬県内でシェアを拡大、または競合からリプレイス（奪取）するか、**「群馬県リース市場における必勝営業戦略およびアプローチプラン」**の立案へと進みます。
