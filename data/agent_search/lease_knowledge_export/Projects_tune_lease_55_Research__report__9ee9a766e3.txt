# リースの基本定義と種類の整理

本セクションでは、リース取引をこれから学ぶ初心者に向けて、**「リースの基本的な定義」**、実務で混同されがちな**「レンタルや割賦（分割払い）との違い」**、そしてリースの2大柱である**「ファイナンス・リース」と「オペレーティング・リース」の特徴と違い**を、図解的表現と詳細な比較表を用いて体系的に整理・解説します。

---

## 1. リース取引の基本定義
### リース取引とは？
リース（Lease）とは、企業が選択した機械設備や車両などの物件を、**リース会社が代わりに購入し、その企業に対して中・長期にわたって有料で賃貸（リース）する取引**のことです。

「賃貸借（貸し借り）」の契約ではありますが、実質的には**「設備資金の融資（ファイナンス）」を受けて設備を導入する**ことと非常に近い性質を持っています。

### リース取引の3者間スキーム
リース取引は、一般的に**「ユーザー（借手）」「リース会社（貸手）」「サプライヤー（販売会社・メーカー）」**の3者間で成立します。

```
 [1. 物件の選定・交渉] ───>  【サプライヤー】 (メーカー・ディーラー)
          │                             ▲
          │                             │ [3. 物件購入契約] / [5. 納入・保守]
          ▼                             │
   【ユーザー】 ──────────────────> 【リース会社】
   (賃借人/借手)    [2. リースの申し込み]     (賃貸人/貸手)
                <──────────────────
                  [4. リース契約・リース料支払]
```

#### 【取引のステップ】
1. **物件の選定**：ユーザーがサプライヤーから、自社が必要とする仕様・価格の機器（パソコン、複合機、車両など）を選定します。
2. **リースの申し込み**：ユーザーがリース会社に、その物件をリースしてほしいと申し込みます。
3. **物件購入契約**：リース会社がサプライヤーに対し、ユーザーに代わって物件の売買契約を結び、購入代金を支払います。
4. **リース契約の締結・支払**：リース会社とユーザー間で「リース契約」を結び、ユーザーはリース会社に毎月「リース料」を支払います。
5. **物件の納入**：サプライヤーからユーザーへ物件が直接納入され、使用を開始します。

## 2. リースと「レンタル」「割賦販売」の違い
初心者が最も混同しやすい「リース」と「レンタル」、さらには「割賦販売（分割払いでの購入）」の違いを徹底比較します。

これらの最大の違いは、**「誰が物件を選び、誰が維持管理（保守や税金対応）をするか」**、そして**「中途解約ができるかどうか」**にあります。

### 三者の機能比較表

| 比較項目 | リース（ファイナンス・リース） | レンタル | 割賦販売（ローン・分割） |
| :--- | :--- | :--- | :--- |
| **取引の本質** | 金融（資金調達の代替） | 賃貸借（一時的な使用） | 割賦購入（分割購入） |
| **対象となる物件** | **新品**（ユーザーが自由に選択） | **中古・在庫**（業者の保有物から選択） | **新品・中古**（ユーザーが自由に選択） |
| **標準的な契約期間** | 中長期（2年〜7年程度） | 短期（日単位〜1年未満が中心） | 長期（耐用年数などに応じる） |
| **中途解約** | **原則不可**（解約時は違約金が発生） | **いつでも可能**（予告期間が必要な場合あり）| **不可**（残債の一括返済が必要） |
| **保守・修繕義務** | **ユーザー（借手）**が負担 | **レンタル会社**が負担 | **ユーザー（購入者）**が負担 |
| **所有権の帰属** | リース会社に帰属 | レンタル会社に帰属 | 完済時にユーザーに移転 |
| **固定資産税・保険** | リース会社が処理（リース料に含む） | レンタル会社が処理 | ユーザーが自身で申告・納税・加入 |
| **メリット** | 初期費用を抑えて最新設備を導入可能 | 必要な時だけ使える、いつでもやめられる | 最終的に自社の所有物（資産）になる |
| **デメリット** | 途中解約ができず、購入より総額が高くなる | 長期で借りると1日あたりのコストが割高 | 固定資産税の支払いや廃棄の手間が自社にかかる |

## 3. 主要なリース取引の種類：2つの仕組み
リース取引は、大きく分けて**「ファイナンス・リース」**と**「オペレーティング・リース」**の2つに分類されます。この違いを理解することが、実務において最も重要です。

---

### ① ファイナンス・リース（Finance Lease）
日本国内の企業間リース取引の約7〜8割を占める、最もスタンダードな方法です。実質的には**「借入金で物件を購入した状態」**に非常に近い取引です。

#### 成立するための「2つの要件（要件定義）」
以下の2つの特徴（日本の会計基準等による規定）をどちらも満たす場合、ファイナンス・リースと判定されます。

1. **ノンキャンセラブル（解約不能）**
   契約期間中、原則としてユーザー側から**契約を解除（中途解約）することができません**。どうしても解約する場合は、残りの期間のリース料に相当する「規定損害金（違約金）」を一括で支払う必要があります。
2. **フルペイアウト（フルカバー）**
   リース会社が物件を購入するために費やした「物件価格」「金利」「固定資産税」「動産総合保険料」などの**ほぼ全額（概ね90%以上）を、ユーザーが支払うリース料で賄う（回収する）**仕組みになっています。

#### ファイナンス・リースの2つの小分類
* **所有権移転外ファイナンス・リース（主流）**：契約満了後も、物件の所有権はリース会社にあります。ユーザーは物件を「返却」するか、格安の「再リース料」を払って使い続けるかを選びます。
* **所有権移転ファイナンス・リース**：契約満了後に、物件の所有権がユーザーに無償（または格安）で移転する契約です。

---

### ② オペレーティング・リース（Operating Lease）
ファイナンス・リース「以外の」リース取引を指します。実質的には**「レンタルに近い中・長期の賃貸借」**です。

#### 最大の特徴：「残存価値（残価）」の設定
オペレーティング・リースでは、リース終了時の**「その物件の予想中古売却価値（残存価値＝残価）」**をあらかじめ見積もります。
そして、**【物件価格】から【残価】を差し引いた金額**をベースにしてリース料を計算します。

```
【ファイナンス・リース】
  [ 物件価格 100% ＋ 諸経費 ] ＝ すべてリース料としてユーザーが支払う

【オペレーティング・リース】
  [ 物件価格の一部 ] ＋ 諸経費 ＝ ユーザーがリース料として支払う
                 └─ [ 残価（数10%）] ＝ リース終了後にリース会社が売却等で回収
```

#### 特徴とメリット
* **リース料が安い**：残価を差し引いて計算するため、ファイナンス・リースに比べて毎月のリース料が大幅に安くなります。
* **中途解約の柔軟性**：契約内容によっては、一定のルールのもとで中途解約が認められる場合があります。
* **対象物件**：中古市場が確立されており、将来価値（残価）を見積もりやすい「車両（カーリース）」「PCなどのOA機器」「航空機」「船舶」「工作機械」などでよく使われます。

---

### ファイナンス・リースとオペレーティング・リースの比較表

| 比較項目 | ファイナンス・リース | オペレーティング・リース |
| :--- | :--- | :--- |
| **実質的な性格** | お金の融資を受けて購入する取引に近い | 物を純粋に借りる取引に近い |
| **フルペイアウト** | **あり**（物件代金の100%近くを払う） | **なし**（物件代金の一部だけを払う） |
| **残存価値（残価）設定** | 原則なし | **あり**（リース会社が残価リスクを負う） |
| **月々のリース料** | 割高（総額＝物件価格＋諸経費） | **割安**（残価を引いた分だけを支払う） |
| **契約終了時の選択肢** | ①返却、②再リース（安価） | ①返却、②再リース、③買い取り（市場価格） |
| **主な対象物件** | 汎用性が低く長期で使用する設備全般 | 車両、航空機、PC、汎用工作機械など |
| **会計処理（日本の中小企業）** | 賃貸借処理（支払リース料として全額費用化） | 賃貸借処理（支払リース料として全額費用化） |
| **会計処理（大企業・IFRS適用企業）**| **オンバランス処理**（資産・負債に計上） | **オンバランス処理**（原則すべて資産・負債に計上）※ |

> 💡 **【プロの視点：新リース会計基準の動向について】**
> 現在、日本の会計基準（大企業・上場企業対象）は、国際会計基準（IFRS 16号）に合わせる形で大きな改正が進められています。
> これにより、従来は「オフバランス（資産に載せず費用処理）」にできていた**オペレーティング・リースであっても、原則としてすべてのリース取引を「オンバランス（資産・負債としてバランスシートに計上）」することが義務付けられる**流れとなっています。ただし、**中小企業については、引き続き「支払リース料」として簡単に経費処理できる**特例（中小企業の会計指針）が維持される見込みです。

## 4. 初心者向け：導入判断クイックフロー
自社が新しい設備を導入する際、どの契約形態（購入・リース・レンタル）を選ぶべきかを判断するための簡易フローチャートです。

1. **使用期間はどのくらいか？**
   * **数日〜1年未満の短期** ──> **【レンタル】** が最適。
   * **数年〜中長期** ──> 次のステップへ。

2. **その設備は最終的に自社の所有物にしたいか？**
   * **はい（自社資産にしたい）** ──> **【一括購入】** または **【割賦販売（分割払い）】**。
   * **いいえ（使えればよい・処分が面倒）** ──> 次のステップへ。

3. **技術的な陈腐化（古くなるスピード）が早いものか？（例：PC、サーバー等）**
   * **はい（3年前後で最新型に替えたい）** ──> **【オペレーティング・リース】**。残価を引いた安いリース料で、期間終了後に返却し次の新機種へ。
   * **いいえ（5〜7年など、耐用年数いっぱい使い切る）** ──> **【ファイナンス・リース】**。固定資産税の管理などをリース会社に任せて、長期的に均等額で利用。
