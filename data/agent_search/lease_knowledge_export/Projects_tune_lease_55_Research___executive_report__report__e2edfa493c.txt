# 【エグゼクティブ・マスターレポート】群馬県リース市場の規模・競争環境・未来展望

**〜「ものづくり県」における百花繚乱のリース経済圏と勝者の戦略〜**

---

## 1. エグゼクティブ・サマリー

本レポートは、群馬県におけるリース市場規模を多角的な推計モデルから算出し、同市場に参入する主要リース会社の競争環境、シェア構造、および将来の成長トレンドを体系的にまとめた総合調査報告書です。

### 1.1 調査の目的と背景
群馬県は、全国平均を大きく上回る製造業比率（県内総生産の37.2%）を誇る北関東屈指の「ものづくり県」です。活発な民間設備投資需要、車社会に裏打ちされた旺盛な移動手段需要、そして広大な農業基盤を有しており、多様なリース需要が交錯する極めて魅力的な市場を形成しています。本調査は、この潜在的な市場ポテンシャルを可視化し、競争戦略を策定するための基礎データを提示することを目的としています。

### 1.2 核心的発見（Key Findings）
1. **二層構造の市場規模**
   * **一般リース市場規模**（リース事業協会統計準拠）：**約 610億円 〜 680億円（基準値：650億円）**。
   * **広義リース・レンタル市場規模**（オートリース・建機等含む）：**約 950億円 〜 1,100億円**。
2. **「1強＋5強＋専門特化」の競争構造**
   * 地方銀行トップクラスの基盤を持つ群馬銀行グループの**「群銀リース」がシェア36.9%（年間取扱高 約240億円）**を占め、圧倒的な地域絶対王者として君臨しています。
   * これに対し、高崎支店を拠点に北関東をカバーする**大手総合リース5社（合計シェア約30.4%）**が大型製造・脱炭素・IT案件で競合。さらに、**リコーリース、オリックス、JA三井リース**などの専門特化型プレイヤーが独自ドメインで強固な牙城を築いています。
3. **成長のドライバー**
   * 製造業の国内回帰に伴う「スマートファクトリー化（GX/DX）」、2050年脱炭素化へ向けた「自家消費型太陽光やEVインフラ投資」、そしてIT機器の「所有から利用（LCM）」への移行が市場を再構築しています。

## 2. 群馬県リース市場規模の推計と構造分析

群馬県の主要な経済指標、産業構造の特徴、および全国のリース統計データを掛け合わせ、群馬県内におけるリース市場規模（年間契約取扱高）を算出しました。

### 2.1 推計の前提となる基礎データ
市場規模の推計にあたり、以下の公的および業界公表データをベンチマークとして採用しています。

> **【全国リース市場ベンチマーク（近年平均値）】**
> * 全国年間リース取扱高（一般リース）：約 4.2兆円 〜 4.5兆円
> * 全国民間企業設備投資額：約 95兆円 〜 100兆円
> * 一般リース浸透率（民間設備投資に占める割合）：**約 4.5% 〜 5.0%**
> * 日本の名目GDPに対する一般リース市場の比率：**約 0.72%**
>
> **【群馬県経済指標（群馬県県民経済計算より）】**
> * 群馬県名目県内総生産（県内GDP）：**約 9兆1,500億円**（全国シェア：約1.6%）
> * 群馬県民間企業設備投資額：**約 1兆1,800億円**
> * 産業構成比（第2次産業）：**37.2%**（全国平均：26.2%）

---

### 2.2 市場規模推計の3つのアプローチ
より精緻な市場規模を導き出すため、異なる3つの論理アプローチから検証を実施しました。

#### アプローチA：県内総生産（GDP）対比モデル
全国の名目GDPに対する一般リース取扱高の比率（0.72%）を、群馬県の名目県内総生産に適用して算出。
$$\text{市場規模(A)} = 9\text{兆}1,500\text{億円} \times 0.72\% \approx 658.8\text{億円}$$

#### アプローチB：民間企業設備投資額 × リース浸透率モデル
群馬県の民間設備投資額に、製造業比率の高さ（一般に製造業のリース活用率は高い）を考慮した微修正リース浸透率（5.2%）を適用。
$$\text{市場規模(B)} = 1\text{兆}1,800\text{億円} \times 5.2\% \approx 613.6\text{億円}$$

#### アプローチC：産業構造加重補正モデル（最精緻）
群馬県の産業別設備投資額（製造業：非製造業 ＝ 約55 : 45）に、各セクター別のリース利用特性を掛け合わせて積算。

| 産業セクター | 推計設備投資額 | 推計リース浸透率 | 推計リース取扱高 | 主なリース対象機種 |
| :--- | :---: | :---: | :---: | :--- |
| **製造業セクター** | 6,490億円 | 5.5% | **約 357億円** | 工作機械、産業用ロボット、検査機器 |
| **非製造業セクター** | 5,310億円 | 5.2% | **約 276億円** | 情報通信機器、店舗設備、オフィス什器 |
| **合計（一般リース）**| **1兆1,800億円** | **5.36% (平均)** | **約 633億円** | - |

#### 【検証と合意値】
3つの独立したアプローチ（659億円、614億円、633億円）は極めて高い精度で収束しており、**群馬県における一般リース市場の年間取扱規模は「約610億〜680億円」**と定義するのが妥当です。

さらに、リース事業協会統計に含まれにくい非加盟会社や、他分野の市場規模を加算した「実質的なリース・レンタル経済圏」は以下の通りです。

```
 ┌─────────────────────────────────────────────────────────┐
 │ ■ 一般リース市場規模（統計ベース）：約 610億〜680億円    │
 ├─────────────────────────────────────────────────────────┤
 │   ＋ オートリース（自動車リース）：約 180億〜220億円     │
 │   ＋ 建設機械レンタル・リース市場：約 160億〜200億円     │
 ├─────────────────────────────────────────────────────────┤
 │ ■ 広義リース・レンタル市場：約 950億〜1,100億円         │
 └─────────────────────────────────────────────────────────┘
```

### 2.3 機種（セグメント）別需要分析
群馬県の産業構造を強く反映した、機種別取扱シェアの推計値です。全国平均と比較して、**「産業機械」および「輸送機械」の比率が高い**ことが特徴です。

```
【群馬県リース機種別市場シェア（推計）】
■■■■■■■■■■■■■■■■■■■■ 31.0%  情報通信機器（PC、サーバー等）
■■■■■■■■■■■■■■■■ 24.0%  産業機械（工作機械、成形機等）
■■■■■■■■■■ 15.0%  輸送機械（車両、物流・フォークリフト等）
■■■■■■■ 11.0%  事務用機器・OA機器
■■■■■ 9.0%   商業・サービス用設備
■■■ 6.0%    医療用機器
■■ 4.0%     その他（建設機械等）
```

* **情報通信機器（約201億円 / 31.0%）**: DX推進、サイバーセキュリティ対応に伴うPC・サーバーの定期的なリプレイス。
* **産業機械（約156億円 / 24.0%）**: 太田市（SUBARU関連）、伊勢崎市、高崎市の工業集積における工作機械、マシニングセンタ等の投資需要。
* **輸送機械（約98億円 / 15.0%）**: 物流結節点（北関東自動車道等）としてのトラック、および高密度の法人・個人営業車フリート需要。

### 3.3 競合他社のプロファイルとポジショニング分析

#### ① 地銀系リース会社
* **群銀リース (シェア 36.9%)**: 群馬銀行（県内メインバンクシェア約50%）の強固な顧客基盤とシームレスに連動。圧倒的な資金力と決裁スピードにより、県内の中小・中堅企業リテール案件を事実上スイープしている絶対王者。
* **東和リース (シェア 3.1%)**: 第二地銀である東和銀行系列。地元密着型の店舗網から小規模小売・地場建設会社等のニッチ需要を拾い上げ、確実な囲い込みを行う。

#### ② 大手総合リース会社（高崎支店を構える主要5社）
交通のハブである高崎駅周辺に拠点を構え、群馬・栃木・新潟の広域をターゲットに活動しています。
* **三菱HCキャピタル**: 工作機械や産業ロボットなど、工場の自動化（FA）投資案件に抜群の強み。
* **三井住友ファイナンス＆リース (SMFL)**: スバル等を含む大手企業向けの大型設備投資（数十億円規模）や、大規模環境（メガソーラー等）にフォーカス。
* **東京センチュリー**: ITアセット（PCやサーバー等）の調達から廃棄までを統括するLCM（ライフサイクルマネジメント）や、太陽光・蓄電池などの脱炭素ソリューションに強み。
* **みずほリース**: 商社（丸紅等）との協業ルートを活用した、グローバル進出企業や大手ベンダー向けのリース展開。
* **芙蓉総合リース**: 県内病院・医療機関に対する医療機器リース、および地方自治体向けのアウトソーシング・オフィス機器調達に強み。

#### ③ メーカー系・独立系・その他の主要プレイヤー
* **オリックス**: 直接取引（メーカーを介さない提案営業）により、中堅・中小企業に対して計測器レンタル、自動車、一般機械の複合パッケージを提供。
* **JA三井リース**: JA（農協）グループの系統独占ルートを有し、群馬県が誇る大規模「農業セクター」のトラクター、ビニールハウス、食品加工設備等で不動のシェアを誇る。
* **リコーリース**: 複合機をトリガーとしたオフィスIT環境の構築、および個人経営クリニック（歯科・内科等）向け医療設備リテールのフロントランナー。

## 4. 市場環境の多面的評価（PEST & SWOT分析）

群馬県リース市場の現在地を俯瞰するため、マクロ環境（PEST）と、市場を構成する3大勢力の内部・外部環境（SWOT）を分析します。

### 4.1 PEST環境分析

* **Political（政治・行政）**: 群馬県の「5つのゼロ宣言（2050年脱炭素化）」を背景に、県や市町村が省エネ設備に対する補助金政策を拡充。グリーンリース推進の追い風に。
* **Economic（経済）**: サプライチェーンの再構築（国内回帰）に伴う、太田・伊勢崎等の工業団地における工場増設の動き。一方で、金利上昇局面への移行はリース料率に影響。
* **Social（社会・労働）**: 急激な生産年齢人口の減少（人手不足）に対応するため、自動化ロボット、AGV（自動搬送車）、および農業分野でのスマート機械化が急務。
* **Technological（技術）**: 企業のDX（デジタルトランスフォーメーション）推進による、レガシーIT（物理サーバー等）から最新クラウド/LCMアセットへの移行加速。

## 5. 成長トレンドと市場攻略アクションプラン

### 5.1 今後を左右する4大成長トレンド
1. **スマートファクトリー投資への傾斜**
   工場の省人化・省力化に向けたマシニングセンタや産業ロボットの導入は一過性のトレンドではなく、今後10年の主流となります。
2. **グリーン・トランスフォーメーション（GX）のマネタイズ**
   「自家消費型太陽光」「EVトラック・営業車」のリース化に対し、補助金申請から施工、保守までをリース会社が統括して提供するモデルが伸長しています。
3. **ITアセットのLCM（ライフサイクルマネジメント）化**
   PCなどのデバイスを単に貸すだけでなく、初期キッティング（セットアップ）から廃棄時のデータ消去までを「月額サブスクリプション」として提供するLCMサービスが一般化しています。
4. **スマート農業への金融サポート**
   高額な自動操縦トラクターやドローンなどの導入が進んでおり、担保評価の難しい新技術に対するJA三井リース等の機動力が期待されています。

```
                           │
 ┌─────────────────────────┴─────────────────────────┐
 │ ③ ネットワーキングとチャネル開拓（ベンダー連携、サブメイン化）  │
 └───────────────────────────────────────────────────┘
```

#### アクション1: 「補助金ワンストップGXパッケージ」による製造業への切り込み
* **対象顧客**: 電気料金高騰に悩む、太田・伊勢崎・高崎エリアの中堅・中小金属/プラスチック加工工場。
* **具体策**:
  * 省エネエアコン・LED・太陽光パネルの販売代理店と協働し、「実質電気代削減額 ＞ 毎月のリース支払額」となるシミュレーションをパッケージ化。
  * 群馬県および各地方自治体が拠出する省エネ補助金の申請プロセスをリース会社側が100%引き受け、「初期費用ゼロ・手続不要」で最新省エネ設備を導入できるスキームで他社の単純金利型リースをリプレイスする。

#### アクション2: 情シス担当者救済型「LCM PCサブスク」による地銀顧客層の奪取
* **対象顧客**: 専任のIT管理者が不在、あるいは負荷が限界に達している従業員30〜150名規模の中堅企業。
* **具体策**:
  * 単にPCをファイナンス（リース）として提案するのではなく、**「初期設定（キッティング）＋故障時即代替機発送＋5年後データ完全消去証明書付き回収」**をワンパッケージにしたLCMモデルを展開する。
  * 「金融商品」として比較される金利競争から脱却し、「情報システム部門のアウトソーシング」としてアピールすることで、群銀リース等の一般リース契約の満了時に自社モデルへと乗り換え（リプレイス）を促す。

#### アクション3: スマホ完結型「ベンダーポータル」提供による販売店囲い込み
* **対象顧客**: 地場の有力OAディーラー、医療機器商社、産業機械卸。
* **具体策**:
  * ベンダーの営業担当者が顧客の前で瞬時にリース見積書を発行でき、そのままスマホ上で審査登録が可能な「簡易ポータルシステム（API連携）」を提供する。
  * 地銀系リースの弱みである「夕方以降や土日の与信回答の遅さ」を補う、AI審査による「10分以内即時仮与信」をフックにすることで、販売店における「推奨指定リース会社（ファーストチョイス）」のポジションを獲得する。

## 6. 次なるステップと未来のロードマップ

群馬県のリース市場で持続的なシェア拡大と優位性を確保するための、向こう3年間のフェーズ別実行ロードマップを提示します。

```
【群馬県リース市場 攻略ロードマップ】

 2024年 (Phase 1: チャネル開拓)
 ├─ [重要地場ベンダーのアライアンス開拓] ─> OA・医療・産業機械ディーラーとの連携強化
 └─ [即時審査ポータルのパイロットテスト] ─> 営業現場での機動力向上

 2025年 (Phase 2: ソリューション浸透)
 ├─ [GX（省エネ・脱炭素）リースの横展開] ─> 製造業へ「補助金＋設備」のセット提案
 └─ [IT LCMモデルの営業アプローチ本格化] ─> 中堅企業へ「所有から利用」への転換訴求

 2026年 (Phase 3: 市場シェア奪取)
 ├─ [群銀リース満了案件への競合リプレイス] ─> 付加価値サービスをフックに攻勢
 └─ [オートリース等を含めた広義の囲い込み] ─> 企業アセット全体の統合提案
```

### 結び
群馬県は、地元の絶対的インフラである**群銀リースが強固な要塞**を築いている一方で、企業のDX（デジタル転換）やGX（グリーン転換）といった**「単なるお金の貸し借りでは解決できない経営課題」が噴出している市場**でもあります。

競合他社がこの市場で勝ち残るためには、地銀が得意とする「低金利の叩き合い」を避け、**「アセットに高い付加価値を付与して提供するサービス一体型リース（アセットファースト戦略）」**をいかに迅速かつ顧客フレンドリーに提案できるかが、成功を分ける最大のキーファクターとなるでしょう。
