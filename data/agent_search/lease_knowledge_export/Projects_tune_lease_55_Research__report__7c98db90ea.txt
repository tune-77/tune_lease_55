# 栃木県における企業向けリース利用実態分析 報告書

本報告書では、栃木県内の主要産業（製造業、農業、建設業、観光・サービス業、医療・福祉）におけるリースの利用傾向、導入されている設備の種類、および県内企業が抱える具体的なリース導入ニーズや動向について詳細に分析します。

---

## 1. 栃木県の産業構造とリース利用傾向の全体像

栃木県は、北関東における強固な経済基盤を有しており、特に**「製造業の比率が極めて高い（県内総生産の約36%）」**という特徴があります。一方で、全国有数の農業県（いちご、米、畜産など）としての側面や、日光・那須を抱える観光地としての側面、そして宇都宮市を中心とする広域商業圏としての側面も併せ持っています。

この多様な産業ポートフォリオが、県内リース市場の「多角的な需要」を形成しています。

### 図1：栃木県における産業別リース利用浸透度と主要導入設備

```
【製造業】（浸透度：極めて高い）
 └── 工作機械、産業用ロボット、射出成形機、コンプレッサー、測定器、フォークリフト

【建設・土木業】（浸透度：高い ※レンタル含む）
 └── ICT建機、バックホウ、高所作業車、仮設ハウス、ドローン

【農業・畜産業】（浸透度：中〜高 ※制度資金併用）
 └── 大型トラクター、自動環境制御システム、搾乳ロボット、ドローン

【観光・サービス・小売業】（浸透度：中）
 └── 業務用空調（省エネ）、POSレジ、厨房機器、LED照明、ホテル・旅館向け什器

【医療・福祉】（浸透度：極めて高い）
 └── MRI・CT、電子カルテシステム、介護用特殊ベッド、送迎用福祉車両
```

## 2. 主要産業におけるリース利用実態の詳細

### (1) 製造業（ものづくり産業）
栃木県には「清原工業団地（宇都宮市）」「平出工業団地（宇都宮市）」「芳賀工業団地（芳賀町）」「真岡工業団地（真岡市）」など、日本屈指の規模を誇る内陸型工業団地が集積しています。自動車（日産自動車、本田技研工業等）、電気機械、医療機器などの大手メーカーと、その広大なサプライチェーンを形成する地場の中小・中堅部品メーカーが多数存在します。

* **主な導入設備**:
  * **工作機械・生産設備**: マシニングセンタ、NC旋盤、プレス機械、プラスチック射出成形機。
  * **自動化・省力化機器**: 産業用多関節ロボット、搬送用AGV（無人搬送車）。
  * **工場付帯・ユーティリティ設備**: スクリューコンプレッサー、局所排気装置、フォークリフト、自家消費型太陽光発電設備（PPA・リース）。
* **具体的な利用動向とニーズ**:
  * **陳腐化リスクの回避と経営資源の集中**: 技術革新のスピードが速い半導体関連や精密電子部品の検査機器・測定器は、買取ではなく「5〜7年のファイナンスリース」で導入し、常に最新鋭の機器に入れ替える傾向が顕著です。
  * **中小企業経営強化税制の活用**: 税制優遇（即時償却や税額控除）を受けるため、証明書（工業会証明書等）を発行できる指定設備（B類型など）をリースで導入するケースが非常に多く見られます。
  * **脱炭素（GX）への対応**: サプライチェーン全体でCO2削減が求められる中、老朽化した油圧式射出成形機から省エネ型電動射出成形機への更新、あるいはLED照明や高効率空調へのグリーンリース（環境配慮型リース）の適用が増加しています。

### (2) 農業・畜産業（フードバレーとちぎ）
栃木県は「とちおとめ」「とちあいか」に代表されるいちごの生産量が日本一であり、米（コシヒカリ）、白ネギ、さらには那須地域を中心とした酪農・畜産業が非常に盛んです。近年、就農者の高齢化と労働力不足を背景に、「農業のスマート化」が進んでおり、これがリース需要を押し上げています。

* **主な導入設備**:
  * **スマート農業機器**: 自動操舵GPS搭載大型トラクター、自動ドローン（農薬・肥料散布用）。
  * **環境制御・生産管理設備**: ビニールハウス用自動環境制御システム（温度・湿度・日射量の自動制御およびCO2施用装置）、自動パッキング・選別機。
  * **畜産設備**: 自動搾乳ロボット（酪農向け）、自動給餌システム。
* **具体的な利用動向とニーズ**:
  * **初期投資（イニシャルコスト）の抑制**: 1台数千万円に達する大型トラクターや搾乳ロボットは、個人の農家や農業生産法人にとって購入が困難です。これをリースにすることで、月々のランニングコストに平準化しています。
  * **国・県の補助金事業との連携**: 「強い農業づくり総合支援事業」や「農業機械リース支援事業」などの補助金を活用し、補助対象外となる残額部分を共同リースや割賦契約で賄うニーズが定着しています。

### (3) 建設業・土木業
県内の社会インフラ整備や、近年多発するゲリラ豪雨・台風による河川改修等の防災・減災工事を担う建設業は、地域経済に不可欠な存在です。

* **主な導入設備**:
  * **ICT施工機器**: 3次元設計データと連動して動くICTバックホウ、ブルドーザー。
  * **現場用設備**: ユニットハウス（現場仮設事務所）、高所作業車、敷鉄板。
* **具体的な利用動向とニーズ**:
  * **リースとレンタルの「ハイブリッド使い分け」**:
    * **レンタル**: 特定の工事（数ヶ月間）のみ使用する特殊建機や敷鉄板、仮設ハウスはレンタルで調達。
    * **リース**: 通年で使用する標準的なバックホウ、ダンプカー、営業用車両は「3〜5年のリース」で調達し、資産を持たないオフバランス化を志向。
  * **i-Constructionへの追随**: 国土交通省が推進するICT施工に対応するため、高額なGNSS（全球測位衛星システム）搭載建機をリースで導入する中堅ゼネコンが増加しています。

### (4) 観光業・サービス業・小売業
日光、那須、塩原などの一大リゾート・温泉地を抱える栃木県において、観光産業（ホテル・旅館）は主要な外貨獲得源です。また、宇都宮市などの都市部では商業施設や飲食店がひしめき合っています。

* **主な導入設備**:
  * **観光・宿泊施設**: 業務用厨房機器、客室用エアコン（空調）、省エネ給湯器、キャッシュレス決済端末、客室向けテレビ・スマート機器。
  * **小売・飲食**: POSレジシステム（インボイス・電帳法対応）、プレハブ冷蔵ショーケース、店舗内LED照明。
* **具体的な利用動向とニーズ**:
  * **電気代高騰に対する「省エネ設備リース」の急増**: 旅館やホテルの光熱費が高騰しており、初期投資ゼロで月々の電気代削減効果からリース料を賄う「ESCO（エスコ）型リース」や「省エネ空調リース」の相談が、足利銀行系リース会社や大手総合リース会社に殺到しています。
  * **IT導入補助金の活用**: 小売・サービス業において、インボイス制度対応のためにPOSレジやクラウド型会計・基幹システムを導入する際、リース契約を組み合わせて初期負担を極小化するニーズが高まりました。

### (5) 医療・福祉分野
栃木県内には「自治医科大学付属病院（下野市）」や「獨協医科大学病院（壬生町）」などの北関東を代表する巨大な特定機能病院が存在するほか、県内各地に中規模病院、クリニック、そして高齢化に伴う介護施設が多数設置されています。

* **主な導入設備**:
  * **高度医療機器**: MRI、マルチスライスCT、超音波診断装置（エコー）、人工透析装置。
  * **IT・管理システム**: 電子カルテシステム、PACS（医用画像管理システム）。
  * **福祉・介護**: 特殊浴槽、介護用リクライニングベッド、移乗サポートロボット、デイサービス送迎用の福祉車両（スロープ・リフト付き）。
* **具体的な利用動向とニーズ**:
  * **技術的陳腐化への対策（医療機器）**: 検査機器や診断装置は5〜6年で画質や機能が劇的に向上するため、購入（自己所有）すると将来的なリプレイスが困難になります。「再リース（期間満了後に割安な料金で1年ずつ延長契約する）」も視野に入れた期間設計のリース利用が標準化しています。
  * **メンテナンスリース（車両・機械）**: 送迎用車両や特殊浴槽などは、万が一の故障が事業停止に直結するため、車検や定期メンテナンスをすべてパッケージ化したリースが好まれます。

## 3. 設備種別からみる具体的なリース導入トレンド

栃木県内企業の最近の動向として、特に顕著なリース導入の「3大トレンド」を解説します。

### ① DX（デジタルトランスフォーメーション）とITリース
* **背景**: 2023年10月のインボイス制度開始、および2024年1月の改正電子帳簿保存法（電子取引データの保存義務化）の完全義務化。
* **動向**:
  * 県内中小企業におけるPC、サーバー、ネットワーク機器（UTM等のセキュリティ機器）のリプレイスが急増。
  * 従来「ソフトウェアは購入するもの」という認識が強かったものの、クラウド移行が進み、ソフトウェアライセンスやSaaSの利用料をリース会社がファイナンスする（「IT・ソフトウェアリース」や「サブスクリプション仲介サービス」）ケースが一般化。

### ② GX（グリーントランスフォーメーション）と環境リース
* **背景**: 栃木県および宇都宮市は、カーボンニュートラル社会に向けたロードマップを提示しており、企業の省エネ・創エネへの取り組みに対して積極的な支援を行っています。
* **動向**:
  * **自家消費型太陽光発電のリース導入**: 工場や商業施設の屋根に太陽光パネルを設置する際、初期費用なしで導入できるリースモデルの活用が進んでいます。
  * **高効率空調・LEDへの一斉切替**: 中小製造業の工場や旅館において、電気料金高騰の直撃を受けたことで、削減された電気料金をリース支払いに充てる「ゼロ円導入スキーム」が地元金融機関経由で提案され、好調な動きを見せています。

### ③ オートリースと「物流の2024年問題」
* **背景**: 栃木県は宇都宮上三川IC、鹿沼IC、佐野藤岡ICなど東北自動車道・北関東自動車道の結節点であり、物流倉庫や配送拠点が非常に多い「北関東の物流ハブ」です。
* **動向**:
  * **ドライバー不足・残業規制（2024年問題）対策としての車両更新**: 配送ルートの最適化に向けたデジタコ（デジタルタコグラフ）や車載カメラ、運行管理システムを搭載した新鋭トラック（いすゞ、日野等）をリースで一括調達する動き。
  * **企業の営業車アウトソーシング**: 営業車両のメンテナンスリース移行。車検・保険・タイヤ交換・事故時対応の手間をすべてリース会社に一任（BPO化）することで、管理部門の人手不足に対応しています。

## 4. 栃木県内企業のリース導入における特有の課題とニーズ

県内企業の財務担当者や経営者層へのヒアリング・動向調査から浮かび上がる、栃木県ならではの課題とニーズは以下の通りです。

| 課題・ボトルネック | 県内企業のニーズ | 解決のためのアプローチ（リース会社の提案） |
| :--- | :--- | :--- |
| **地元重視・顔の見える関係性** | 地元の状況をよく知る担当者と、スピーディーかつ柔軟に契約手続きを進めたい。 | **足利銀行系列（あしぎんリース）等**が、地銀の支店網と密着した与信・提案体制を強みとしてシェアを獲得。 |
| **事業承継期における契約移行** | 経営者の高齢化により、次世代（子息や親族）に事業を承継する際、多額の保証債務やリース契約がネックになる。 | 親族内承継時に**リース契約の名義変更・保証人の見直し（個人保証の免除等）**を円滑にサポートするファイナンシャル提案。 |
| **補助金採択とのタイミング調整** | 国・県の補助金（ものづくり補助金、省エネ補助金等）が採択される前に契約をしてはいけないという制限ルールへの対応。 | 採択決定後に速やかに発注・リース実行を行えるよう、**リース会社がメーカー・販売ディーラーと密に連携する調整機能**。 |
| **リースアップ（終了）後の適正処理** | 産業廃棄物の適正な処理や、PC・サーバー内の機密データ消去に関する不安。 | データ消去証明書の発行や、リサイクル・適正な廃棄ルートを担保した**アセットマネジメント機能付きリース**の提供。 |

## 5. 次のステップ（リース会社シェア分析）への接続

本分析により、栃木県内には、
* **製造業（ものづくり現場）における産業機械・ロボットの需要**
* **物流・車社会におけるオートリースの安定需要**
* **DX・GXを背景としたIT・環境関連の急成長需要**

という巨大な市場ニーズが確実に存在していることが明確になりました。

次のステップである**「リース会社のシェアを調査して」**では、
1. 地元の圧倒的王者である**「あしぎんリース」**
2. 準地場・広域として浸透する**「常陽リース」「群銀リース」などの近隣地銀系**
3. 全国展開する**大手総合リース会社（東京センチュリー、オリックス、三菱HCキャピタルなど）**
4. 自動車や工作機械、複合機などの**「メーカー系リース会社（日産フィナンシャル、リコーリース等）」**

これらがどのようなポジショニングをとり、栃木県という魅力的な市場を争っているのか、その競合状況とシェア構造を具体的に明らかにします。
