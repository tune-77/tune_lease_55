# 栃木県リース市場 総合分析レポート
**〜市場規模・利用実態・競合シェアの統合から見える全貌と未来への戦略〜**

本レポートは、栃木県におけるリース業界の市場規模、産業別の利用実態、および主要参入プレイヤーの競争環境について行われた調査結果を体系的に統合し、同県におけるリース市場の全貌、今後の重要課題、そして新たなビジネスチャンスを浮き彫りにすることを目的として作成されました。

---

## 1. 栃木県リース市場の構造と規模（統合分析）

栃木県のリース市場は、**「ものづくり大県（製造業比率36.2%）」**としての産業特性を色濃く反映し、北関東において茨城県に次ぐ極めて活発で底堅いBtoB市場を形成しています。

### (1) 市場規模の俯瞰
統計データおよびマクロ経済指標からの推計により、栃木県における物品賃貸業およびリース市場の全体像は以下の通り定義されます。

```
【栃木県物品賃貸業 年間売上高】 約 1,240 億円
     │
     ├── 【純リース市場規模（売上ベース）】 約 868 億円（※レンタル等を除く）
     │
     └── 【新規リース年間取扱高（フロー）】 約 770 億 〜 870 億円（※設備投資連動）
```

* **全国的な位置づけ**: 栃木県の県内総生産（約9.6兆円）の全国シェア（1.72%）にほぼ比例する規模を維持。
* **高いリース浸透率**: 民間設備投資額（約7,525億円）に対するリース浸透率は、全国平均（5.0%〜6.0%）を上回る**6.5%〜7.5%**と推計されます。これは、リース適性の極めて高い工作機械や製造ラインなど「重厚長大アセット」の導入割合が高いためです。

### (2) 機種別（対象物件別）シェアと市場ポテンシャル
栃木県の新規契約ベースにおける機種別シェアは、全国平均と比較して「産業・工作機械」の比率が高い点が最大の特徴です。

```
【栃木県 新規リース機種別シェア（推計：年間約800億円規模）】

 █ 産業機械・工作機械（約30%：240億〜260億円）
 █ 情報通信機器（約22%：180億〜200億円）
 █ 輸送用機器（約20%：160億〜180億円）
 █ 商業・サービス業用設備（約10%：80億〜90億円）
 █ 医療機器（約8%：65億〜75億円）
 █ その他（約10%：80億〜90億円）
```

## 2. 産業別利用実態と「3大成長トレンド」

栃木県内企業の現場では、経営効率化、人手不足対策、そして外部環境の変化（制度改正・電気代高騰など）に対応するため、リースを戦略的に活用する動きが強まっています。

### (1) 産業別の主要導入設備とドライバー
* **製造業（ものづくりサプライチェーン）**: 自動車（日産・ホンダ）、電機、医療機器の集積地。生産年齢人口の減少を背景に、マシニングセンタや産業用ロボット、AGV（自動搬送車）の導入が加速。中小企業経営強化税制を活用した「B類型（即時償却等）」のリース利用が標準化。
* **農業・畜産業（フードバレーとちぎ）**: いちご、米、酪農が盛ん。数千万円規模の自動操舵GPS搭載トラクターや自動搾乳ロボットを、リース活用（国のリース補助事業連携）で初期投資を抑えて導入。
* **建設業（インフラ・防災対策）**: 東北道・北関東道の交差する交通要衝としてのインフラ維持、河川改修に伴い、ICT建機をリース（通年使用分）とレンタル（スポット使用分）で賢く使い分ける「ハイブリッド調達」が浸透。
* **観光・サービス・小売業**: 日光・那須の旅館や宇都宮の商業エリア。急激な電気代高騰に対応するため、初期投資ゼロで高効率空調やLED、省エネ給湯器を導入する「ESCO型・グリーンリース」への関心が極めて高い。
* **医療・福祉分野**: 医科大学・大病院からクリニックまで、技術的陳腐化リスクの高いMRI/CT、電子カルテを「再リース」前提の期間設計で導入。介護福祉分野でのリフト付き送迎車のメンテナンスリース需要も堅調。

### (2) 市場を牽引する「3大成長トレンド」
1. **DX（デジタルトランスフォーメーション）リース**: インボイス制度・電帳法完全義務化に伴うPC・サーバーの刷新。さらに、従来「買取」が常識だったソフトウェアやクラウド（SaaS）ライセンスの利用料をリース会社がファイナンスする「SaaSリース」が急増。
2. **GX（グリーントランスフォーメーション）リース**: 栃木県および宇都宮市の「カーボンニュートラルロードマップ」に呼応した、企業の「自家消費型太陽光発電システム（PPA・リースモデル）」や省エネ工場の構築。
3. **オートリースのBPO（業務アウトソーシング）化**: 「物流の2024年問題」に直面する県内物流拠点における、新鋭トラックへのリプレイス。営業車両をメンテナンスリースに移行することで、総務・管理部門の車両管理業務をリース会社へアウトソーシング（BPO）するニーズの増大。

## 3. 競合シェアと市場支配構造のダイナミクス

栃木県のリース市場は、地元第一地方銀行をバックボーンとするメガ地銀系リース会社が「絶対王者」として君臨し、それを全国系、隣接地銀系、メーカー系が包囲する構造となっています。

### (1) 県内競合シェア構造（推計）

```
【栃木県リース市場シェア（新規取扱高ベース）】

┌───────────────────────────────────────┬───────────┐
│ 地元金融機関系 (めぶき・とちぎ等)     │ 約 43%    │
├───────────────────────────────────────┼───────────┤
│ 全国系総合リース (オリックス・大手メガ等)│ 約 30%    │
├───────────────────────────────────────┼───────────┤
│ メーカー系・専門 (リコー・JA三井等)    │ 約 15%    │
├───────────────────────────────────────┼───────────┤
│ 隣接県・広域地銀系 (群銀等)            │ 約 12%    │
└───────────────────────────────────────┴───────────┘
```

### (2) 主要プレイヤーの強みとポジショニング
* **めぶきリース（シェア約35%）**: 足利銀行の県内全支店と連携した「銀・リース一体提案」で圧倒的トップ。地方自治体、医療機関、地元の有力中堅企業を盤石に抑え、近年は「サステナビリティ・リンク・リース」等のESG金融でも市場を牽引。
* **とちぎリース（シェア約8%）**: 栃木銀行の顧客基盤である中小・零細・小売をターゲットとし、大手では対応できないスピーディーかつ親身な対応力が強み。
* **群銀リース（シェア約10%）**: 群馬銀行の顧客が多い栃木県西部（足利・佐野など「両毛経済圏」）に深く浸透。製造業の補助金対応ファイナンスに高い専門性。
* **オリックス（シェア約12%）**: 宇都宮支店の強力な「直販部隊」を軸とし、カーリース（オリックス自動車）の圧倒的調達力、およびメガソーラーや環境ビジネスのノウハウで差別化。
* **メガバンク系（三菱HC・東京センチュリー・三井住友F&L：合計約18%）**: 県内に所在する大手メーカー（日産、ホンダ、キヤノン等）の巨大工場や、高額なマテハンシステム、東京本社のスプリット案件（東京で折衝し栃木で導入）を一手に引き受ける。
* **リコーリース（メーカー系）**: 県内販売ディーラーと連携し、複合機・PCなどオフィスITの小口（スモールチケット）契約で絶対的な強み。

### (3) 栃木県内の「3大激突エリア」
市場では、顧客層とニーズが重なる以下の3つの領域で激しい戦いが繰り広げられています。

## 4. 栃木県リース市場のSWOT分析

栃木県の産業構造と現在の競合環境から、市場の現状を強み（S）・弱み（W）・機会（O）・脅威（T）の4つの軸で整理しました。

| 強み（Strengths） | 弱み（Weaknesses） |
| :--- | :--- |
| * 製造業（36.2%）の厚い地盤による産業機械需要<br>* 「車社会」「物流ハブ」を背景とした旺盛なオートリース需要<br>* 足利銀行を軸とした地域金融とリースの一体提案モデルの確立 | * 特定の大手工場やサプライチェーンへの依存度が高い<br>* リース会社（特に地場）におけるIT・デジタルアセットに対する目利き力の発展途上<br>* 大手総合系による低金利（料率）攻勢に対する価格競争耐性の低さ |
| **機会（Opportunities）** | **脅威（Threats）** |
| * 法人・工場における「脱炭素（GX）投資」の本格化<br>* 人手不足対策としての省力化投資（ロボット・自動化）<br>* 電帳法・インボイス対応を契機としたSaaS・ソフトウェアリースの台頭<br>* 農業分野での「スマート農業」移行に伴う大型設備需要 | * 急激な金利上昇局面におけるリース料率（調達コスト）の上昇<br>* 県内中小企業の経営者の高齢化と「事業承継問題」に伴う市場縮小<br>* 2024年問題による地元運送業者の経営圧迫と設備投資の冷え込み |

## 5. 栃木県内企業（利用者）が抱える課題とボトルネック

リースを導入・活用するにあたり、栃木県内の企業や経営者が直面している特有の課題があります。これらの解決こそが、今後のリース会社の競争優位性につながります。

1. **個人保証（経営者保証）と事業承継の壁**:
   多くの地場中小企業が経営者の交代期（事業承継期）を迎えています。先代のリース契約に付随する「個人保証」の解除や、後継者への円滑な契約引き継ぎがボトルネックとなるケースが増加しています。
2. **補助金（ものづくり・省エネ等）とリースのタイミング不一致**:
   補助金の採択決定前に設備を発注・契約してはならないという厳格なルールが存在します。販売ディーラー、顧客、補助金事務局との間で、リース会社が「調整弁」として機能しないと、補助金不採択や契約遅延に繋がります。
3. **リースアップ（期間満了後）の適正処理とセキュリティ不安**:
   特にPCやサーバーなどのIT機器において、機密データ消去の安全性（証明書発行）や、産業廃棄物としての適正処理（リサイクル）プロセスを明確に求める企業が増えています。

## 6. 今後のビジネスチャンスと推奨戦略（提言）

栃木県における約800億円のリース市場を攻略し、新たなビジネスチャンスを掴むための「4つの戦略的アプローチ」を提言します。

```
┌─────────────────────────────────────────────────────────┐
│              【栃木県リース市場 攻略ロードマップ】               │
├────────────────────────────┬────────────────────────────┤
│   [戦略①：スマート農業の深耕]   │    [戦略②：伴走型GXリースの展開]   │
│ ─ 農機リースと補助金一体型提案 ─ │ ─ 削減電気代で支払うESCO型推進 ─ │
├────────────────────────────┼────────────────────────────┤
│  [戦略③：SaaS・サブスクの金融化]  │   [戦略④：事業承継一体型ファイナンス]  │
│ ─ IT化・業務ソフトのリース組成 ─ │ ─ 経営者保証解除を武器とした囲い込み ─ │
└────────────────────────────┴────────────────────────────┘
```

### 戦略①：「スマート農業」のファイナンス深耕
* **ターゲット**: 農業生産法人、大規模いちご農家、酪農家。
* **アプローチ**: JAや地元農機ディーラーと密に連携し、大型自動トラクターや搾乳ロボットに対して「残価設定型リース」や「補助金連動割賦」をパッケージ化。農林中金系のノウハウを地銀が代理店として展開するスキームの構築。

### 戦略②：「削減実績連動」の伴走型GX（グリーン）リース
* **ターゲット**: 中小製造業（工場）、日光・那須エリアのホテル・旅館。
* **アプローチ**: 「サステナビリティ・リンク・リース」を一歩進め、高効率空調やLED、自家消費太陽光を「初期投資ゼロ」で導入し、**「削減された電気料金の実績値からリース料を支払う（ESCO型）」**スキームを地盤金融機関が主導。地元への安心感と最先端GXの融合。

### 戦略③：SaaS・ソフトウェアリースのプラットフォーム化
* **ターゲット**: バックオフィスIT化が遅れている地場中小・零細企業。
* **アプローチ**: 単なるハードウェア（PC本体）のリースから、会計ソフト、販売管理SaaS、インボイス対応クラウドの5年間使用権を合算してリース化（ソフトウェアライセンス・サブスクファイナンス）するパッケージ。地元のITベンダー（リコー系ディーラーや地元大手のSIer）とのアライアンスが不可欠。

### 戦略④：事業承継・経営者保証免除をフックにした「顧客囲い込み」
* **ターゲット**: 社長が60代以上の、事業承継を控える中堅・中小企業。
* **アプローチ**: 金融庁の「経営者保証非ガイドライン」に基づき、一定の財務規律を満たす企業に対しては**「経営者個人保証なしのリース契約」**を積極的に提示。承継時にリース契約の名義変更・保証人見直しをワンストップで支援することで、他社（競合地銀系・全国系）からのリプレイス（ひっくり返し）を狙う。

## 7. まとめ

栃木県のリース市場は、強力な製造業基盤、車社会・物流ハブ特性、そして活発な観光・農業といった「多面的な需要」に支えられた非常に魅力的なマーケットです。

これまでは「足利銀行（めぶきグループ）の牙城」として、地元の信頼関係が最優先される傾向が強かったものの、今後は**「単に金利で貸す（従来のファイナンスリース）」から、「企業のDX・GX、事業承継の課題を解決するサービスを提供する（アセットマネジメント・コンサル型リース）」**へと本質的なシフトが起こっています。

地元金融機関系リース会社は「地域密着の信頼とスピード」を武器にさらにデジタル・環境対応を進め、全国系や隣接地銀系は「高度な専門ソリューション（PPAやデータ消去、補助金支援）」を尖らせてアプローチすることが、栃木県市場での勝敗を決する鍵となるでしょう。
