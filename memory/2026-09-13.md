## Promotable Items
- TradeMemoryの接続は、人間の `helped / used / challenged / rejected` 評価だけを証拠数で縮約した最大±1.2点の補助値として案件想起順位へ反映する。成約・失注だけで有効性を断定せず、審査スコア・自動承認・自動昇格には接続しない。
- Cloud Run Web版のBasic認証成功後は、Secure / HttpOnly / SameSite=Strictの30日間セッションCookieを使う。同じブラウザでは再入力を省き、未認証アクセスは引き続き401で拒否する。
- PageIndexは長文・テキスト主体PDF向けの任意評価サイドカーに限定する。本番RAG、Obsidian、スコア、プロンプト、判断資産へ自動接続せず、明示的な `--execute` がある時だけモデルを呼ぶ。
