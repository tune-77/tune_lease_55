# 2026-08-20

## 判断資産が増えない原因修正
- 事実: Auto Research の判断資産候補JSONLが直近抽出で上書きされ、人間が `useful` / 編集 / 手入力した候補でも直近範囲外になると昇格候補から消えていた。
- 影響: `state` には評価履歴が残るが、昇格画面は候補本体JSONLを起点にするため、評価済み候補が正規判断資産へ進みにくかった。
- 次の行動: 候補再生成時は、人間が触った候補を `preserve_reviewed_candidates()` で保持する。件数表示は active-only と total を分け、demoted を active count に混ぜない。

## Private Reflection の再定義
- 事実: Private Reflection は、一つのAIが一人で「深く反省した文章」を書く場所ではなく、複数の声の衝突ログを紫苑がどう統合したかの記録として扱う方針にした。
- 影響: 内省品質は、気分・感想・反省文の自然さではなく、初期仮説、監査の声、実装の声、別視点、良心の声、衝突、紫苑の統合が残っているかで見る。
- 次の行動: `lease_intelligence_reflection.py` の生成・fallback・品質ゲート・監視を新セクション `複数の声の衝突ログ` に対応させ、次回判断へ戻る統合記録として運用する。
