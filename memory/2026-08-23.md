# 2026-08-23

## Cloud Run ニュースダイジェスト再同期
- 事実: Cloud Run 版のニュースダイジェストは、`lease_news_digest.find_vault()` が startup 時点の Vault だけを読むため、稼働中の更新を取りこぼしていた。`lease_news_digest.py` に Cloud Run だけの GCS Vault 再同期ガードを追加し、`find_vault()` 呼び出し時に一定間隔で `/tmp/gcs_vault` を更新するようにした。
- 影響: ニュースダイジェスト、注目論点、朝報のニュース表示が、再デプロイや再起動なしでも最新の Obsidian Vault へ追随しやすくなった。
- 次の行動: Cloud Run のニュース系は startup-only sync ではなく、再同期が効いているかをまず確認する。`USE_GCS_VAULT=true` のまま動かしている限り、Vault 更新後の反映タイミングを必ず見る。

## 短期・中期・長期記憶の実配線
- 事実: `use_mid_term_memory` を `chat_context_budget` に追加し、`/api/chat` に `mid-term-continuity.md` を新しい prompt block として差し込んだ。あわせて Cloud Run 用の公開メモリパックは `PERSISTENT_MEMORY.md` も長期側に拾うようにした。
- 影響: 記憶が「保存されているだけ」で終わらず、短期は会話運び、中期は数日単位の継続論点、長期は判断原則として役割分担できるようになった。
- 次の行動: もし記憶が効いていないように見えたら、まず `mid-term-continuity.md` と `use_mid_term_memory` の budget を見る。RAG を疑うのはその後。
